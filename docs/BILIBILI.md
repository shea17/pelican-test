## 简介（整段复制）

一只鹈鹕骑着自行车，从撒哈拉岩壁一路骑到代码编辑器里。
137 秒，二十个时代，一条连续的长卷，没有一次剪辑。

【这是什么】
《鹈鹕测试 / The Pelican Test》是一支程序生成的短片。
二十段画面并排接成一条长卷，镜头一直向右走，鹈鹕在卷上骑，画风在接缝处换掉。
接缝扫过骑手的那一瞬，前半只鸟还是旧画法，后半只已经是新画法——轮心、车架、身体，
一像素都不会错位。这是全片唯一"炫技"的地方，也是我最想让你盯着看的地方。

【怎么做的】
全片没有一张手绘图、没有一个素材文件。
画面由 p5.js 实时绘制、逐帧导出；骨骼是一套参数化的鹈鹕加自行车，
二十种画风只是二十套"画法"，动作始终是同一套——所以脚踏一圈永远等于两拍。
配乐同样是算出来的：120 BPM，每个版块一种音色，全部由时间轴推出，没有采样。

【时间轴】
00:00 开场：一张纸
00:05 岩壁、墓室、石头与绢（撒哈拉 / 埃及 / 汉画像石 / 唐白描）
00:29 巨峰下的一只鸟（宋代山水）
00:35 汴京的街与河（清明上河图）
00:41 另一条路上的神（玛雅 / 莫卧儿 / 八大山人 / 爪哇皮影 / 浮世绘）
01:11 星空、呐喊与吸血鬼（星月夜 / 呐喊 / 诺斯费拉图）
01:29 从示波器到 8-bit（示波器 / 像素 / 聊天窗口 / 蒸汽波 / 竖屏）
01:59 代码里的鹈鹕
02:05 尾声：二十份答卷

【技术】
1920×1080 / 30fps / 137.000 秒 / 4110 帧
渲染：p5.js（WEBGL）+ Puppeteer 逐帧导出 + ffmpeg 合成
音乐：自写合成器（Karplus-Strong 拨弦、FM 钟、气声笛、噪声），48kHz 立体声

## 投稿设置

- **分区**：动画 → 原创动画（次选：科技 → 计算机技术）
- **类型**：自制
- **封面**：两版，按投稿位选。
  先跑 `npm run cover` 生成两张（写到 `docs/media/`，不入库）。
  · 16:9 → `docs/media/bilibili-cover-16x9.png`（1146×717）
  · 4:3 → `docs/media/bilibili-cover-4x3.png`（1146×860）
  各有 2 倍高清版（`@2x`）。素材是第 11.00 秒那一帧：接缝正切在鸟身上。
  改版式在 `tools/cover/cover.html`（16:9）与 `cover-4x3.html`（4:3），跑 `node tools/cover/shot.mjs` 一次出两张。
- **发布**：晚 8–10 点；简介第一行会被当搜索摘要，别写"随便做的小东西"。
